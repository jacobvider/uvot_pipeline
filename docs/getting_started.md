## Google Drive

Google Drive stores images generated by the pipeline as well as manually reviewed detections.

### Candidate Detections

Candidate detections are organized into two folders:

* **Transients** — Images that appear to contain a transient source and require inspection.
* **Not Transients** — Images determined to contain no genuine transient (artifacts, known sources, poor image quality, etc.).

---

### Verified Transients

Confirmed astronomical transients are stored separately and divided into two categories.

#### Follow-Up Observations

These are previously known transients that Swift was intentionally scheduled to observe.

Many originate from external surveys such as the Zwicky Transient Facility (ZTF). Approximately half of the verified detections fall into this category.

#### New Transients

These are potential new discoveries identified by the pipeline.

To distinguish new discoveries from planned observations, the pipeline compares:

* Swift's commanded pointing position
* The detected transient position

If the detected transient lies **more than 2 arcseconds** from the commanded target position, it is considered a candidate new transient.

This criterion is based on Swift's pointing accuracy, which is typically between **1–2 arcseconds**. A larger offset suggests that the source was not the intended observation target.

---

### False Positives

Images determined to be artifacts or otherwise not astrophysical transients are stored in a separate **False Positives** folder.

Examples include detector artifacts, subtraction artifacts, cosmic rays, and other spurious detections.

## Scheduler

The pipeline executes automatically using the Unix scheduling system.

### cron

`cron` is the background service responsible for executing scheduled tasks automatically.

### crontab

The `crontab` file defines **when** the pipeline should run.

The scheduling configuration is stored in:

`uvot_tdrss_crontab.txt`

This file specifies the execution times used on the NASA systems that run the pipeline.
