## high-level description of code:
#### Input:
run "./test_script.sh (target id) (filter)"
#### Output:
-  output files are located in path/to/folder/uvot_pipeline/data/processed/(target id)_(filter)
- it should generate four fits files and a .reg file, all described below
- it will also generate data/reference, which store the reference FITs files (from the swift archive)
- the code will open ds9, and open three fits files. left = difference image, middle = input image, right = reference image

## low-level description of code:
1. opens the input fits file observation <- fits.py
2. gets metadata (ra, dec, obsid, filter, etc) <- fits.py
3. searches for reference image in swift archive (looks within 6 arcmins)  <- archive.py
4. checks that archival reference meets specific criteria <- archive.py
    - different observation (obsid)
    - same filter
    - have exptime > 60 seconds
5. picks archival image with the longest exptime, and then downloads as reference <- archive.py
6. opens reference fits file and selects extension with longest exposure. (the input currently always uses extension 1) <-fits.py, processing.py
7. uses WCS information to find overlapping region of sky between input image file and reference file <- registration.py
8. crops the image file and the reference file to their shared sky area <- registration.py
9. exposure-scales and subtracts cropped images, using HEASoft's uvotimsum, producing imsum_crop.fits <-subtraction.py
10. runs HEASoft uvotdetect on difference images <-processing.py, detection.py
11. creates uvotDetect.fits (output fits catalog containing detected sources) and uvotDetect.reg (DS9 source marker overlay) <- detection.py

## what files are returned?
### ObsCrop.fits
- input observation image
- after it has been cropped to the sky area shared with the selected reference image
- generated by registration.py

### RefCrop.fits
- reference image is chosen from swift archive, using certain criteria (see above)
- it is cropped to the same sky region as the input image
- generated by registration.py

### imsum_crop.fits
- difference image
- RefCrop.fits is subtracted by ObsCrop.fits

### uvotDetect.fits
- each row represents one source detected in imsum_crop.fits
- sky position (ra,dec), measured count and uncertainty (rate, rate_error), source fitting information (shape/size), quality or detection information (flags)

### uvotDetect.reg
- DS9 region file, tells DS9 what shapes to draw over an image
- draws circles around sources that uvotdetect found in the difference image (imsum_crop.fits)
- detection.py runs uvotdetect on imsum_crop.fits
